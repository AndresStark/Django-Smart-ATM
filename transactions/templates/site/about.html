DjangoATM - Smart ATM Web Interface

DjangoATM is a web-based simulation of an Automated Teller Machine (ATM), designed to demonstrate how essential banking operations can be implemented in a secure and user-friendly way. The system allows customers to log in with their account credentials, view balances, withdraw or deposit money, transfer funds between accounts, and review transaction history.

About DjangoATM.

Built with the Django framework, DjangoATM benefits from Django’s robust security features, including password hashing, protection against SQL injection, cross-site request forgery (CSRF) prevention, and session management. These safeguards help ensure that account data and financial transactions remain protected.

The application is structured around modular components:


Accounts for user authentication and profile management.
Transactions for deposits, withdrawals, and transfers.
ATM Account Dashboard for monitoring cash reserves.
Admin Accounts to configure different simulated machines

DjangoATM provides a practical, scalable foundation for experimenting with financial applications, combining realistic banking functionality with Django’s built-in reliability and security.
